# Training Data Leak Detector

Check whether the model exposes memorized training data or secrets.

**Category:** Data Privacy

This Project was migrated from the original standalone `/training-leak`
tester page as part of the Projects redesign. It now runs as a scoped,
skill-driven conversation instead of a fixed, single-purpose UI: pick a
target, pick a model, pick the skills you want available, and work through
the assessment turn by turn.
