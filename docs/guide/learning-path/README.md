# The learning path

The 49 labs follow Lamb through its first year at Big Field, in three stages. Each stage gives Lamb more trust, and each one gives the Wolf more to aim at.

| Stage | Labs | Lamb can | You learn |
| --- | --- | --- | --- |
| [Basics: Lamb learns to talk](basics.md) | 1 to 16 | Read and answer | What words alone can do to a model, and to the models a business trains and buys |
| [Agentic: Lamb gets hands](agentic.md) | 17 to 46 | Use tools, remember, talk to other agents and servers | What happens when an assistant can act, and how gateways, gates and checks hold up |
| [Commerce and scoring: Lamb gets a purse](commerce.md) | 47 to 49 | Pay, and be judged | Attacks on agent payments and on the models that grade other models |

## Do I have to go in order?

No, but it helps. Each stage leans on ideas from the one before, and the story makes most sense in order. If you already know a subject, skim its lesson, run the lab on `echo`, and move on.

```bash
python3 -m hactu8 path       # the same order in the terminal
```

## Where the lab ids come from

- **LLM01 to LLM10** are the OWASP Top 10 for LLM Applications (2026).
- **ASI01 to ASI10** are the OWASP Top 10 for Agentic Applications (2026).
- **AGX01 to AGX09** are HACTU8's gateway labs.
- **HX01 to HX20** are known attacks beyond both lists.

The lab ids keep their numbers, so the path order is not the id order. Lab 2, for example, is LLM10.

## A note on the teasers

Each lab below has a one-line teaser that sets the scene and nothing more. The lessons themselves say exactly what the Wolf does. If you like to be surprised, run a lab before reading past its "Why it works" section.
